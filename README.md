# lichen_specificity

This repo holds the data and analysis for the lichen partner specificity project led by Danielle Ward and Bri Baumbach.

## Vibes

To look at partner specificity.. 

We downloaded GenBank data to see all sequences that had the term photobiont in them using 'rentrez'.

We filtered the hits to ones that had a lichen name in the field using the [World Checklist of Genera of Lichenized Fungi](https://lichenportal.org/portal/checklists/checklist.php?clid=1492&pid=558&dynclid=0).
